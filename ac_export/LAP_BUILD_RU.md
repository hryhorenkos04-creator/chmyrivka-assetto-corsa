# Сборка всего круга

Эта инструкция собирает **весь круг** — 5709 м — вместо одного сектора на
450 м. Получится несколько KN5, которые AC грузит как одну трассу.

## Почему кусками

ksEditor — 32-битная программа, ей доступно около 2 ГБ. Сцена со всеми
модификаторами весит 18.8 млн треугольников. В один KN5 это не кладётся.

Штатный способ AC — файл `models.ini` в корне трассы, где перечислены
несколько KN5. Игра грузит их как одну трассу.

Куски режутся **по пикетажу**, а не по радиусу вокруг точки. Это важно:
каждая грань достаётся ровно тому куску, в чей отрезок попадает её
ближайшая точка оси. Соседи не перекрываются и не оставляют щелей. Если
резать радиусом, на каждом стыке была бы двойная геометрия и мерцание.

**Проезжая часть целиком лежит в первом KN5** — по двум причинам. Физика
дороги должна быть одним куском, и AC читает точки старта `AC_START_*`
только из первой модели: в дополнительном KN5 они не подхватываются.

## Что ещё изменилось

**Фактура на стенах.** 400 материалов из 496 не имели картинки: 318
собраны из процедурных нод Blender, 82 — просто цвет. Ни то ни другое не
переживает FBX, поэтому в игре каждый приезжал одним плоским тоном, и
улица читалась как крашеный картон. Теперь каждому подкладывается одна
из тайловых фотографий, которые уже лежат в сцене (кирпич, бетон, земля,
трава), перекрашенная в его собственный цвет. Цвета у Серёги проставлены
осмысленно — лишь 3 материала из 400 остались на дефолтном сером, — так
что цвет сохраняется, добавляется только фактура.

Перекраска идёт по **яркости**, а не по каналам: иначе красный кирпич,
перекрашенный в кремовую штукатурку, уходил в розовый. И контраст
подрезается ровно настолько, насколько конкретный оттенок может унести
без выбеливания.

**Развёртка.** 1321 объект из процедурных материалов не имел UV вообще —
текстура на такой сетке взяла бы один пиксель и снова стала плоским
цветом. Им считается кубическая проекция по мировым осям, с тайлом в
метрах, так что кладка на стене лежит горизонтально, а на крыше плоско,
и все дома в одном масштабе.

**Чёрные кусты.** Шейдер `ksPerPixel` не имеет ветки альфа-теста, поэтому
флаг `ALPHATEST=1` он игнорировал, и прозрачные пиксели листвы рисовались
своим RGB — чёрным. Теперь материалам с альфой ставится `ksPerPixelAT`.
Альфу несут три текстуры: `broadleaf`, `pine`, `singleleaf`.

**Стволы.** Две коры `V10_Game_Bark_*` съедали 5.7 млн из 9.0 млн,
которые стоит вся растительность, — примерно 2850 треугольников на ствол,
при норме в пару сотен. Упрощать объект целиком нельзя: 2929 деревьев из
3042 держат кору и листву в одной сетке, и Decimate порвал бы
альфа-карточки. Поэтому кора помечается группой вершин, и модификатор
работает строго по ней.

**Фаски.** BEVEL стоит 1.94 млн треугольников, 1.42 млн из них на
зданиях. Фаска в 2 см на коньке крыши в тридцати метрах не видна никогда,
поэтому за заданным расстоянием от трассы они выключаются.

Куски вышли неровными, и это нормально: отрезки одинаковой длины, а

- `models.ini` — 7 записей, формат совпадает со штатными трассами

- **440 ссылок на текстуры из persistence, битых 0**
- шейдеры: 426 `ksPerPixel` и **14 `ksPerPixelAT`** — это листва с альфой
- кубическая развёртка посчитана для 1002 объектов

сделать только человек с установленной игрой.

## Шаг 1. Посчитать, не собирая

Сначала прикидка — она ничего не пишет, только считает:

```powershell
blender --background --python ac_export\export_ac_v17.py -- --scene ПУТЬ\chmyrivka_visual_v17.blend --racing-line ПУТЬ\racing_line_native_v15.json --mode lap --chunks 6 --corridor 45 --drop-bevel-beyond 12 --trunk-ratio 0.2 --merge --dry-run --output ВЫХОД\chmyrivka.fbx
```

Напечатает по строке на кусок: сколько объектов, треугольников и
материалов. **Ориентир — не больше 2.5 млн треугольников на кусок.**
Если больше, подними `--chunks`; если куски вышли крошечные, опусти.

## Шаг 2. Собрать

Та же команда без `--dry-run`, плюс параметры старта:

```powershell
blender --background --python ac_export\export_ac_v17.py -- --scene ПУТЬ\chmyrivka_visual_v17.blend --racing-line ПУТЬ\racing_line_native_v15.json --mode lap --chunks 6 --corridor 45 --drop-bevel-beyond 12 --trunk-ratio 0.2 --merge --flip --start-station 3950 --scale 0.01 --output ВЫХОД\chmyrivka.fbx
```

Обязательные, без них трасса не поедет:

| Ключ | Зачем |
|---|---|
| `--merge` | схлопывает сотни материалов в десятки, иначе ksEditor потребует каждый руками |
| `--flip` | разворачивает старт: без него едешь против часовой |
| `--scale 0.01` | иначе трасса приезжает в 100 раз больше |
| `--start-station 3950` | старт на Сенной |

Появится: `chmyrivka.fbx`, `chmyrivka_s1.fbx` … `chmyrivka_sN.fbx`, по
`.fbx.ini` рядом с каждым, общая папка `texture\` и `models.ini`.

## Шаг 3. Прогнать каждый FBX через ksEditor

Цикл одинаковый для каждого файла:

1. `File → Open`, выбрать `chmyrivka.fbx`
2. `File → Load Persistence`, выбрать `chmyrivka.fbx.ini` рядом
3. `File → Save` — получится `chmyrivka.kn5`
4. Повторить для `chmyrivka_s1.fbx` … `chmyrivka_s6.fbx`

Семь кругов по три минуты. Нудно, но один раз.

Материалы руками назначать не нужно — их проставляет persistence.

## Шаг 4. Положить в трассу

Все `.kn5`, `models.ini` и папку `texture\` — в корень
`content\tracks\chmyrivka\`. Старые KN5 от сектора убрать, иначе
нарисуются поверх.

`models.ini` выглядит так:

```ini
[MODEL_0]
FILE=chmyrivka.kn5
POSITION=0,0,0
ROTATION=0,0,0

[MODEL_1]
FILE=chmyrivka_s1.kn5
POSITION=0,0,0
ROTATION=0,0,0
```

## Что настраивать

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `--chunks` | 6 | сколько KN5 на окружение |
| `--corridor` | 120 | сколько метров по сторонам от оси оставлять |
| `--trunk-ratio` | 1.0 | доля геометрии ствола; 0.2 — игровой ствол |
| `--drop-bevel-beyond` | 0 | за сколько метров гасить фаски; 0 — не гасить |
| `--grain-tile` | 2.0 | метров на один тайл текстуры стены |
| `--no-grain` | — | вернуть плоские цвета вместо фактуры |

Замер по коридору, треугольников на весь круг (сырых, без фасок и без
упрощения стволов):

| Коридор | Треугольников |
|---|---|
| 20 м | 6 374 341 |
| 30 м | 9 275 466 |
| 40 м | 10 848 473 |
| 60 м | 12 599 409 |
| 120 м | 15 225 532 |

Из них растительность — около 63% на любом коридоре. Здания при 40 м
стоят всего 733 тысячи.
