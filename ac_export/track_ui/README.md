# Готовые файлы интерфейса трассы

Кладутся в `content/tracks/chmyrivka/` с сохранением структуры:

    map.png            ->  <трасса>/map.png
    data/map.ini       ->  <трасса>/data/map.ini
    ui/outline.png     ->  <трасса>/ui/outline.png
    ui/preview.png     ->  <трасса>/ui/preview.png
    ui/ui_track.json   ->  <трасса>/ui/ui_track.json

`map.png` и `data/map.ini` — **согласованная пара**: ini объявляет ровно
те WIDTH и HEIGHT, что имеет картинка. Ставить их по отдельности нельзя,
маркер машины уедет с трассы. Сверить после установки:

    WIDTH=1620  HEIGHT=2170  <->  map.png 1620x2170

Лежат в репозитории, а не собираются на месте, потому что `make_map.py`
требует Pillow, а передавать файлы через чат оказалось ненадёжно: пара
однажды разъехалась именно так и день ушёл на диагностику несуществующей
ошибки в координатах.
