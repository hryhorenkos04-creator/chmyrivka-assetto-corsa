# Старобільськ — Чмирівка · v16

Откройте `chmyrivka_visual_v16.blend` в Blender 4.5.7 или совместимой версии. Изображения упакованы внутрь файла. Для оценки материалов используйте **Rendered / Cycles**: режим Solid не показывает итоговый вид материалов и растений.

Это полная исходная Blender-сцена. Установочного мода Assetto Corsa, KN5, записанного игрового проезда и результатов FPS в этом выпуске нет.

## Что изменилось после v15

Рабочий жилой участок — Сінна, **3800–4250 м исходной карты**. У 33 дворов переработаны ограды и ворота; добавлены хозяйственные дорожки, грядки, неоднородный грунт и немного бытовых предметов. Новые садовые деревья собраны группами в боковых и задних частях дворов; некоторые дворы намеренно оставлены открытыми. У северного поворота, **2260–2600 м исходной карты**, доработаны существующие кроны и подлесок. Это локальный художественный проход, а не одинаковая детализация всех 5,7 км.

Стекло представляет тонкую поверхность с частичным отражением и прямым пропусканием света; сохранены настоящие углубления окон и существующие шторы. Почти фронтальные окна в тени могут оставаться тёмными. Изменение шейдера само по себе не выдаётся за заметный выигрыш в каждом кадре.

Основная дорога, высоты, 33 секции поребриков, проектная линия v15, боковые примыкания и пит-лейн сохраняются. Боксы по-прежнему справа после **4993 исходной карты**. Точность фасадов и положения отдельных растений не подтверждена адресной фотосъёмкой; это региональная художественная реконструкция внутри имеющейся картографической сцены.

- `comparisons/contact_sheet_v16.png` — общий лист десяти кадров.
- `comparisons/comparison_*_v16.png` — подписанные сравнения без ретуши.

Старый декоративный материал и заменённые меши сохранены в сцене. Скрытые прежние ограды, трава, поребрики и накат не нужно снова включать при экспорте. Новые объекты сгруппированы в `66_V16_Residential_Environment`.

## Тестовый перенос материалов

Отдельный архив сектора содержит исправленную вырезку текущей сцены, скрипты переноса и фактические результаты ограниченного запекания. Область — **стены и верхние крыши шести домов**, а не все материалы участка. `AC_TRANSFER_V16_RU.md` объясняет охват и потери мелкой фактуры при выбранном разрешении. Roughness Blender нельзя автоматически считать параметром отражения шейдера AC. Полная настройка игровых материалов, коллизий, старта, ИИ и запуск выполняются отдельным этапом.

## Повторная сборка

Готовый `.blend` открывается самостоятельно. Для повторной сборки изменений нужен неизменный `chmyrivka_visual_v15.blend` из предыдущего выпуска с SHA256 `2d4b6f1d09903d69a2361cc479a7d86451d14d084e393e0fa4a2f1c3f7a7217c`. Положите его в соседнюю папку `../chmyrivka_v15/` или передайте `--source`.

Среда: Python 3.11, bpy 4.5.7, NumPy, Shapely, SciPy, Pillow. Необходимые JSON входят в `source_data/`, вспомогательный код — в `dependencies/v15/`.

```bash
python build_v16.py
python render_v16.py --scene chmyrivka_visual_v16.blend --output screenshots_v16
python render_v16.py --scene chmyrivka_visual_v16.blend --output screenshots_extra_v16 --cameras data/extra_cameras_v15.json
python tools/validate_v16.py --source ../chmyrivka_v15/chmyrivka_visual_v15.blend --candidate chmyrivka_visual_v16.blend --change-report data/change_contract_v16.json --map-data source_data/surroundings_local.json --output validation_v16.json
```

Тяжёлые процессы bpy запускайте последовательно. Скрипты проверки и рендера не сохраняют проверяемые исходники. Снимки местности, просмотренные для исследования, не включены в распространяемые архивы; их источники перечислены в `VISUAL_TARGET_V16_RU.md`. Лицензии исходных карт и текстур находятся в `sources/`.
