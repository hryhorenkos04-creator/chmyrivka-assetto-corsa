# Материалы v06: источники и масштаб

Для поверхностей используются готовые PBR-материалы Poly Haven и ambientCG: сканированные поверхности и процедурная натуральная трава. Это общие материалы асфальта, земли, травы, бетона и кирпича, а не снимки конкретных улиц Чмирівки. Они улучшают вид поверхности, но не подтверждают материал каждого реального дома.

Все перечисленные файлы имеют лицензию **CC0 1.0**. Официальная страница лицензии: https://polyhaven.com/license. Страница прямо разрешает использование, изменение и передачу файлов вместе с собственным проектом, в том числе коммерческим. Дополнительная официальная лицензия ambientCG: https://docs.ambientcg.com/license/. Авторы приведены добровольно. Проверено 13 октября 2026 года.

Для каждого материала загружены карты Diffuse, Normal OpenGL и Roughness в разрешении 2048 × 2048 JPEG. Небо — HDR, основной файл 4096 × 2048; прежний вариант 2048 × 1024 сохранён. Всего 20 файлов, 96 978 455 байт. Файлы Poly Haven проверены по MD5 официального API. Для ambientCG архив проверен при чтении ZIP/CRC; MD5 извлечённых карт вычислены локально. Точные пути, хеши и ссылки загрузки записаны в `textures_manifest.json`.

Масштаб взят из поля dimensions API, где значения представлены в миллиметрах, и сверен с отображаемым масштабом на странице. Например, для Rough Concrete API содержит 1230 мм, а страница округляет значение до 1,2 м.

## Подключение

- Diffuse: цветовое пространство sRGB → Base Color.
- Roughness и Normal OpenGL: Non-Color; normal подключать через узел Normal Map с корректными UV/касательными. Metallic = 0.
- На дороге и земле использовать физический масштаб в метрах; для стен сохранять направление кирпичных рядов и размер кирпича.
- HDRI: линейное изображение → Environment Texture → Background. Нужны корректная экспозиция и поворот; при добавлении отдельного солнца избегать несовместимых двойных теней.
- Крупные трещины асфальта повторяются вместе с тайлом. Для длинных видимых участков нужны вариации покрытия/ремонтные заплаты, чтобы рисунок не повторялся механически.
- Проверены все шесть карт цвета: крупной направленной падающей тени или дорожной разметки нет; присутствует обычная мелкая затенённость углублений.
- Sparse Grass имеет выраженный коричнево-зелёный тон и редкую растительность. Основной зелёный грунт переведён на Grass 001; Sparse Grass оставлен как возможный материал сухих или вытоптанных пятен. Для ближнего плана нужны дополнительные объёмные стебли; масштабирование до гигантских пучков некорректно.

`textures/download_assets.py` позволяет повторить загрузку выбранных файлов по сохранённым официальным URL. Метаданные API находятся в `textures/metadata/`. При загрузке использован идентифицирующий User-Agent проекта согласно условиям публичного API: https://github.com/Poly-Haven/Public-API/blob/master/ToS.md.

## Коррекция после проверки рендера

Текстура Sparse Grass оказалась слишком коричневой для выбранного зелёного сезона. Проверены Leafy Grass и Grass Ground из Poly Haven: первая содержит много опавших листьев, вторая сухая; в итоговый набор они не включены. Выбран ambientCG Grass 001: густой зелёный покров со смесью травы и небольших широких листьев. Это художественный сезонный выбор, а не доказательство состояния растительности на конкретную дату.

Для неба добавлен HDRI 4K, потому что панорама 2K давала недостаточную детализацию облаков при рендере 1920 пикселей. Первоначальные карты сохранены; настройки сцены должны использовать 4K как основной фон.
