# Старобільськ — Чмирівка · v17

Откройте `chmyrivka_visual_v17.blend` в Blender 4.5.7 или совместимой версии. Для оценки материалов и растений используйте **Rendered / Cycles**. Режим Solid не показывает итоговые материалы. Полный `.blend` предназначен для самостоятельного открытия; исходная v16 нужна только для повторной сборки изменений.

Существующие контрольные камеры в сцене: `V11_19_DRIVER` — начало жилого участка; `V11_30_DETAIL` — примыкание и фасады; `V12_08_DETAIL` — крупный вид обновлённого дома. Дополнительную камеру на отметке 3985 м создаёт рендерер по `data/extra_cameras_v17.json`; она не сохраняется обратно в исходный `.blend`.

Это исходная Blender-сцена. Установочного мода Assetto Corsa, KN5, игрового проезда и измерений FPS в выпуске нет. Качество игрового шейдинга и производительность в AC этим выпуском не подтверждаются.

## Область прохода

Работа v17 сосредоточена на **близких фасадах и передних частях дворов Сінної**, примерно 3800–4250 м исходной карты. Цель — улучшить то, что видно из машины, и проверить результат на совпадающих водительских кадрах. Фактический состав изменений, численные результаты проверки и оставшиеся визуальные недостатки приведены в `CHMYRIVKA_STATUS_RU.md`, `VALIDATION_V17_RU.md` и `VISUAL_REVIEW_V17_RU.md`.

Это локальная художественная доработка. Она не означает одинаковой детализации всего круга. Контуры домов и положение улиц опираются на сохранённую картографическую основу; новая отделка, конструктивные детали и посадки являются региональной реконструкцией. Адресная точность фасадов не подтверждена полной серией местных фотографий.

Постоянные требования проекта: **A → E → B → C → D → A**, ширина трассы 8–14 м, рельсы только на обочинах, видимые боковые улицы за ограждениями. Боксы расположены справа после **4993 м исходной карты**, вход пит-лейна — 5015 м карты. Проектная линия и поребрики v15 сохраняются; динамический проезд болида остаётся отдельной проверкой.

## Просмотр изображений

- `screenshots_v17/` — шесть основных ракурсов текущей полной сцены.
- `screenshots_extra_v17/` — пять дополнительных видов, включая новый водительский ракурс на отметке 3985 м карты.
- `screenshots_before_v16/` и `screenshots_extra_before_v16/` — соответствующие одиннадцать исходных видов v16. Новый водительский кадр также снят в неизменной v16.
- `comparisons/gallery_v17.html` — автономная галерея всех новых и исходных кадров; открывайте после распаковки архива целиком.
- `comparisons/contact_sheet_v17.png` — общий лист одиннадцати новых кадров.
- `comparisons/comparison_driver_v17.png` — два водительских сравнения.
- `comparisons/comparison_architecture_v17.png` — близкие фасады.
- `comparisons/comparison_layout_v17.png` — контроль расположения дворов.

Сравнительные листы используют фактические рендеры с одинаковыми камерами и настройками. Ретушь деталей сцены не применяется; для листов изображения только уменьшаются и дополняются подписями. Северный поворот, поребрик и пит-зона включены для контроля контекста, а не как заявление о новых доработках этих участков.

## Перенос в игру

В v17 новый набор запечённых материалов не создаётся. `sources/AC_TRANSFER_V16_RU.md` описывает **историческую выборочную проверку v16** для стен и верхних крыш шести домов. Её результаты нельзя автоматически считать проверкой изменённых материалов v17. Отдельные секторные `.blend`, карты запекания и архив переноса v16 в этот выпуск не продублированы.

Для игрового выпуска ещё нужны материалы и оптимизация всего выбранного сектора, прозрачность растений, повторяемая мелкая фактура, коллизии, стартовые точки, ИИ, экспорт через ksEditor и фактический проезд в Assetto Corsa. План этапов — `CHMYRIVKA_ROADMAP_RU.md`.

## Повторная сборка

Основа — `chmyrivka_visual_v16.blend` с SHA256 `8e4f2c9c3e1b37de42d9d99edf115a898fa72cb76936dce19020bb02f23b0e00`. Положите файл предыдущего выпуска в соседнюю папку `../chmyrivka_v16/` или передайте `--source` сборщику. Исходные JSON входят в `source_data/`, вспомогательный код — в `dependencies/`.

Среда: Python 3.11, bpy 4.5.7, NumPy, Shapely, SciPy, Pillow. Тяжёлые процессы bpy запускайте последовательно.

```bash
python build_v17.py
python render_v17.py --scene chmyrivka_visual_v17.blend --output screenshots_v17
python render_v17.py --scene chmyrivka_visual_v17.blend --output screenshots_extra_v17 --cameras data/extra_cameras_v17.json
python tools/validate_v17.py --source ../chmyrivka_v16/chmyrivka_visual_v16.blend --candidate chmyrivka_visual_v17.blend --change-report data/change_contract_v17.json --map-data source_data/surroundings_local.json --output validation_v17.json
python make_gallery_v17.py
python package_v17.py
```

Галерея и упаковка требуют полный набор исходных и новых кадров, а упаковка — успешную проверку окончательного SHA сцены и документацию выпуска. Рендерер и валидатор не сохраняют проверяемые `.blend`.

Источники, лицензии и ограничения рельефа находятся в `sources/` и `VISUAL_TARGET_V17_RU.md`. Copernicus GLO-30 DSM не является дорожной геодезической съёмкой. Частные фотографии, просмотренные как референсы, не включены в архивы; их пиксели не использованы как игровые текстуры.
